# Copilot Fold

Microsoft Copilot の過去の回答を折りたたむ、Chrome／Edge 用の拡張機能です。
最新の回答、または手動で選んだ回答だけを開きます。

## 機能

- 会話を開くと、最新の回答だけを表示します。
- 過去の回答を開くと、それ以外の回答を自動で閉じます。
- 開いている回答をもう一度クリックすると、すべて閉じられます。
- 新しい回答が追加されると、その回答を開きます。生成中の本文更新では手動選択を維持します。
- 閉じた回答のボタンにも本文の先頭を表示し、後から読み込まれた本文を反映します。
- 拡張機能のメニューから、一時無効化、最新回答の表示、検出件数の確認ができます。

ユーザーの質問は折りたたみません。

## インストール

1. このリポジトリをダウンロードして展開するか、Git で取得します。
2. Chrome では `chrome://extensions`、Edge では `edge://extensions` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」（Edge では「展開して読み込み」）から、`manifest.json` があるフォルダーを選択します。
5. Copilot のページを再読み込みします。

拡張機能の実行に Node.js や npm は不要です。
更新時は、読み込み元のファイルを更新し、拡張機能の管理画面と Copilot のページをそれぞれ再読み込みしてください。

## 対象

- `https://copilot.microsoft.com/`
- `https://copilot.com/`
- `https://www.copilot.com/`

ブラウザーで開いた上記ドメインの会話画面を対象とします。
Microsoft 365 Copilot の別ドメイン、Edge のサイドバー、Windows アプリ、VS Code は対象外です。

## 描画負荷と制約

閉じた回答には `display: none !important` を適用し、本文のレイアウトと描画を抑えます。
本文の DOM は削除・移動しないため、Copilot による本文更新を維持できます。
会話データはメモリーに残り、Copilot 本体の JavaScript 処理と通信は継続します。
高速化の程度は会話内容や画面の実装によって異なり、性能の実測値は取得していません。

回答の検出には画面の DOM 属性を使います。
Microsoft 側の画面変更やアカウント別の表示差によって、検出できない場合があります。
Shadow DOM と iframe 内部には対応していません。
大量履歴をスクロールした際の、Copilot による要素の再作成についても追加検証の余地があります。

ブラウザー内検索で閉じた本文が見つからない場合は、拡張機能のメニューから一時無効にしてください。
管理画面から拡張機能を無効化・削除した場合は、Copilot のページを再読み込みしてください。

## 回答を検出できない場合

拡張機能のメニューで「回答が検出されない場合」を開き、回答ひとつ分の要素を指す CSS セレクターを指定できます。
現行画面向けの標準条件のひとつは、次のとおりです。

```css
[role="article"][aria-labelledby^="copilot-message-"]
```

質問と回答の両方を含む会話全体の要素は指定しないでください。
空欄で保存すると標準の検出条件に戻ります。

## 権限とデータ

`storage` 権限で有効／無効とカスタムセレクターだけをブラウザー内に保存します。
対象ドメインに挿入する content script で回答の表示状態を変更します。
会話の外部送信・永続保存、外部通信、アクセス解析は行いません。
開いている回答の選択状態はページ内だけで保持します。

## 開発

Node.js 22 以上と npm を使用します。

```sh
npm ci --ignore-scripts
npm run check
npm test
```

Windows の PowerShell で npm の実行が制限されている場合は、`npm` の代わりに `npm.cmd` を使用してください。
テストでは jsdom で会話画面の DOM を再現し、開閉、本文更新、履歴の遅延読み込み、フォーカス管理要素との共存を検証します。
実サイトのすべての表示パターンを保証するものではありません。

Windows で配布用 ZIP を作成する場合:

```sh
npm run package
```

`dist/copilot-fold/` に実行に必要なファイルをまとめ、`dist/copilot-fold-v<version>.zip` を作成します。
依存ライブラリーとテストは ZIP に含めません。

### ファイル構成

| ファイル | 用途 |
| --- | --- |
| `manifest.json` | 対象ドメインと権限 |
| `content.js` / `content.css` | 回答の検出と折りたたみ |
| `popup.html` / `popup.js` / `popup.css` | 拡張機能の設定画面 |
| `test/` | DOM の動作テスト |
| `scripts/package.ps1` | 配布ファイルの作成 |
| `CHANGELOG.md` | 更新履歴 |

手動確認では、最新回答だけの表示、過去回答への切り替え、新しい回答の表示、閉じた回答のプレビュー更新、一時無効化時の復元を確認してください。
